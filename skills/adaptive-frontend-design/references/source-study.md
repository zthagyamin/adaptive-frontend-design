# 把优秀网页学成可执行决定

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

研究空间、内容与表达机制；源站状态不能证明新作品效果。新项目重新寻找参考和素材，同一任务的修订复用未变化材料。

## 选相关的对象，带着决定去看

用户认为当前效果不对并指定参考库时，先从目录进入真实可运行的页面，确认它是完整网站还是单屏概念/录屏。选定主参考后，重新按其主资产、字形、主体面积、前后景与整页衔接制作关键页；旧技术习作的图形、配色和分区不能因为已经写好就自动保留。对照的是用户选择的整体效果，功能清单和数值测试只证明各自行为。

场景主导的页面，主图、模型或透明图层的质量可能先于动效参数决定观感。尽早把最终尺寸的资产与真实标题放在同一画面检查，再扩展运动。原站研究截图和商业资产不自动成为仿作素材；取得可用素材或制作原创替代，并明确因此没有复刻的部分。按当前作品记录借鉴关系和没有复刻的部分，来源归属见[来源说明](../SOURCES.md)。

最多看六个候选，选两至三个与主要任务、内容关系或表达问题相关的页面深看。需要时追加一轮最多两个候选；不能为“还没有最好灵感”持续扩样。

先写要解决的决定：例如如何让图和解释保持关联、怎样兼顾长文和目录、怎样表现物件尺度、怎样让镜头推进叙事。奖项、导航和封面帮助发现来源，不能代替进入真实页面。不同参考提供机制，最终仍服从同一主线。

## 从语义到空间

1. **明确任务与内容。** 分出主体、解释、证据、导航和操作；识别需要同时比较、连续阅读、逐步完成还是体验章节。
2. **看完整范围。** 页顶、主要内容、中段和末段；至少一个关键操作前后；相关加载、展开、返回或媒体状态。动态按正常速度推进观察，记录能证明的范围，不从两张图推断连续流畅。
3. **去装饰画结构。** 用区域、文本块、媒体、动作与空白重建关系。示意标明纵向压缩和估计，不能冒充原图或像素复刻。
4. **联系内容解释几何。** 主辅比例、正文与宽材料的宽度、共享轴线、水平与垂直距离、视觉重量和内容节奏。允许测量时记录真实CSS视口与bounds；只看图则标估计。数值与相应状态绑定，不从截图栅格反推CSS宽度。
5. **同时看排版、色彩和素材。** 字号/字形、行长/行高、色彩角色、边界、图片裁切和光线怎样共同改变重点？CSS字体声明不等于实际字形；素材存在不等于适合此任务。
6. **实际切到手机。** 默认桌面、768、390、320；记主辅如何重新安排、比较距离、文字/图像信息量、导航和返回。实际生效值优先于请求设置值。模拟宽度、触屏、实体手机分别说明。

## 每处重要留白都要讲清

按以下链条写结论：

**观察 → 可能解决的问题 → 作用机制 → 支持证据 → 代价 → 反例 → 可迁移条件。**

先问“它连接或分开了哪两个对象”，再说作用。留白可能来自不同原因：

| 空间 | 要理解的关系 | 不能漏掉的代价 |
|---|---|---|
| 组内/组间距离 | 归属、层级和主题转换 | 太松分裂、太紧混淆，滚动与比较距离变化 |
| 正文两侧 | 行长与导航独立分配 | 压缩代码、数据或图像，空间未用于同时比较 |
| 主对象周围 | 构图平衡、方向、解释或主体重量 | 对象不足时无内容可看，主要信息抵达变晚 |
| 标题/章节之间 | 独立陈述、过渡或情绪停顿 | 切断标题与内容，拖慢主要任务 |
| 控件与边界内部 | 识别、操作和状态归属 | 高频界面密度下降，长标签和URL可用宽度变小 |
| 固定结果预算 | 控件位置稳定、容纳不同结果量 | 少量结果下空间明显，内外双滚动增加复杂度 |
| 未加载空域 | 预留媒体位置或仍在等待 | 不可直接解释成完成构图；须区别加载、失败和零结果 |

导航、宣传、真实学习目标等占用的是内容预算，不能全部称作空白。留白越多并不越好；查找已知词、批量数据和连续说明常需要相称的紧凑关系。

## 解释等级与反面验证

- 官方/作者明确说过意图：保留准确来源，才称明确依据。
- 页面内容、几何和行为与机制相符：称观察支持。
- 准备迁移、尚未比较的决定：称待验证假设。

这些等级不自动产生转化率、眼动、效率或审美提升证据。相同内容的简化对照应预先写清任务、固定项、改变变量和预计结果；同时改间距、底色和布局，只能解释组合结果。源站自然重排不是受控A/B，构造修复也不是历史真实失败。

比较创作工作流时，按共同必需内容、资产和核心路径评价，附加功能单列；核对实际Skill组合、参考读取与预算记录，不把不同工作流写成孤立Skill增量。原图须核对真实视口、滚动位置和操作状态后才比较首屏占比或信息量。共同输入也须核对语义；维护修订另存，原始输入与结果不回填。条件不齐限定结论，保留改善、退步和无明显差异，不推导普遍审美或速度收益。

手机分查整页溢出、局部滚动、关键控件裁切、固定层遮挡。没有横向滚动仍可能有按钮看不见；局部表格需要滚动也不等于整页撑宽。

## 带走有条件的方法

每个深看页面保留原始可用证据、结构示意、空间/留白分析、跨维联系、手机与未观察项、规则/反例/实现建议。源站不允许存储或复制的材料，只保留允许的观察、链接和原创结构；研究截图不自动成为成品资产。

当任务结构、主线、特点、空间与手机决定、素材和验收已足够明确时，停止研究并实现关键页。达到上限仍有关键缺口，明确要解决的决定，不重置计数或改名继续扩样。

本页描述新项目的有界研究，资料数量不构成每次创作配额。停止条件是关键决定足够明确或达到当前任务约定的研究上限，不为凑数无限浏览。
