# 素材与媒体：先服务任务，再形成一条视觉主线

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

本页为素材条件方法。来源已经按项目汇合；每个新作品仍需准备适用且许可明确、达到其艺术方向的素材组。没有已选素材时保留该制作缺口，不能用分辨率或加载成功证明视觉质量。

素材质量需要实际制作和反馈：跨媒介身份与同构件空间叙述支持有限的材料/观看关系，不能替代摄影、渲染、影片艺术方向、光照、调色、声画与手机专门素材的判断。高分辨率、技术可运行和授权明确都不足以证明素材优秀。

用于选择、准备和呈现图片、视频、字体、声音、模型及环境素材。补充条件、代价与验收见[条件规则补充](conditional-design-rules.md)的 `AS-*`，来源见[来源说明](../SOURCES.md)。本页没有提供任何源站商业资产的转用许可。

## 用内容问题选择媒介

[AS-01](conditional-design-rules.md#as-01)：先问用户要辨认、比较、理解过程、观察空间还是体验故事，再选媒介。把“看起来立体”与“可操作实时空间”分开；强表现任务也不能因实现方便降成静态拼图。

| 要解决的问题 | 可选媒介与条件 | 不够用的情形 |
|---|---|---|
| 辨认外观、读结构、快速比较 | 高质量照片、插图、图解和可放大细节；真实尺寸另给数据 | 单图不能证明复杂运动或背面空间关系 |
| 看操作过程、材料变化或线性故事 | 实拍/动画影片，文案和声音有职责，提供控制与文字内容 | 影片拖动不等于任意相机或几何操作 |
| 自选角度、部位、尺度或配置 | 真实模型与语义 UI，实际输入验证对象变化 | 只换预渲染图片可满足部分配置任务，但不能称实时几何 |
| 探索地点或多幕空间体验 | 可操控场景/用户驱动空间故事，进入退出与定位完整 | 必须快速查事实的任务不应靠漫游获得信息 |

[OP-1](https://teenage.engineering/products/op-1) 的工业摄影与规格组织说明静态媒介可以有强表达；[AirPods](https://www.apple.com/airpods-pro/) 的影片与结构说明不能冒称实时查看；[model-viewer](https://modelviewer.dev/examples/annotations/) 的实际几何切换提供另一类能力。媒介强度不是质量排名。

## 在下载之前确定美术方向与最低可用条件

资产选择按当前主张推进：先明确必须呈现的轮廓、部件或空间关系；再看现有素材在目标尺度/镜头下能否呈现；不足时选择同职责替代、补制或缩减主张并注明影响；最后在最终光线、字体与正文中检查，通过相应代表画面后再扩展长程编排。不是每项未知都阻断交付，只阻断依赖缺失信息的部分。

生产方式服从需要：现有照片可支持识别与裁切；适用且许可明确的模型可支持任意视角；原创建模须真正制作当前镜头所需的结构、厚度和表面；预渲染适合已决定的取景但不冒称实时操作。程序几何在确实表达该造型时可用，复杂主体不能因实现方便被降成任意基本体。保留可编辑原件/生成方式与可追溯派生物，按主张选工具，不强制软件。

代表画面的统一扩展条件见[制作检查](composition-craft.md#代表画面检查与扩展条件)，本页不另建审批或配额。

[AS-02](conditional-design-rules.md#as-02)：素材选择服从当前主体与一条主线。写清内容职责、主体身份、光线/材质、色彩角色、构图方向、摄影或渲染语气，以及和字体/留白的关系。多个来源可共享这些关系，不能只因每张单独漂亮就拼在一起。

先用真实候选素材做关键页小样，再判断是否需要替换或补制。若精度、构图或许可不够，找同职责替代、使用用户授权原件，或在授权范围制作原创素材。AI 生成可用于插画/氛围等合适任务，但不得冒充真实产品照片、实测效果或原作者作品；标明生成与处理身份。

| 维度 | 检查与代价 |
|---|---|
| 内容真实性 | 是否确实对应产品、人物、地点、版本与声明；占位图不能留作真实证据 |
| 清晰与比例 | 按实际显示、裁切和目标设备检查细节；分辨率过高也有传输/解码代价 |
| 构图 | 主体位置是否给标题、说明、控制留空间；背景杂物/高光会不会竞争 |
| 连贯性 | 同一产品各角度材质、白平衡、比例是否相称；不同章节可改变景别 |
| 功能可见性 | 控件、细节与必要对比不被装饰性调色、暗部或景深抹掉 |
| 完整度 | 缺图、透明边缘、色带、循环接缝、字幕和 poster 是否符合展示要求 |

AirPods的外观、内部与使用场景共享产品身份；[New Life](https://sixnfive.com/projects/new-life/) 与 [Audi Rings](https://futuredeluxe.com/work/audi-rings) 提供不同的影像舞台，不能因此把米灰、黑底或某种金属定为所有品牌的默认。[Inside Out 2](https://www.pixar.com/inside-out-2) 的作者研究支持角色/色彩关联；具体比例与“丝滑”概述不升级为普遍公式或连续实测。

## 裁切和响应式版本一起决定

[AS-03](conditional-design-rules.md#as-03)：给每项主媒体标出主体、不可切内容、可牺牲背景和裁切焦点。根据任务在完整显示、局部裁切、另制比例、切换细节之间选择。保留整体比例是任务要求时，不能裁去两端；任务是理解旋钮等局部时，可用近景同时给回看全貌的路径。

手机不只改变像素大小：可让图片/影片先出现、说明在后，重新安排标题与动作；需要时准备不同构图版本。实际检查390、320、平板和桌面中长标题、字幕、重要部位、对照项与控制的关系。对象内部裁切与 DOM 横向溢出分别检查；`overflow-x:hidden` 不能用作掩盖素材/控件被切掉的通用修复。

例如手机保留产品控制面板的局部可能牺牲全貌；画布内提示也可能出画框，即使网页本身没有横向溢出。为媒体预留符合预计比例的空间以稳定布局，同时显示加载状态；已到达画面才能作为最终构图评价对象。

网页显示文件与保存原件分开。按实际显示尺度准备尺寸/编码派生物，近看确有价值的较大版本在需要时加载；保留来源、原件身份、派生方式与说明，不能压缩后丢掉材质/文字等关键依据。用真实请求验证哪些版本在首屏被读入，懒加载标签本身不保证没有提前下载。字节与解码成本帮助定位问题，优化后仍回到最终显示尺度检查，不把某个编码质量值或示例预算写成通用标准。

## 让同一材料在不同观看关系中继续

当页面要解释一个对象的用途、变化或身份时，先把当前主张变成取景问题：需要看见它与谁的尺度、哪处动作或哪种环境关系？整体现形、使用环境、操作近景和结构图各有用处，只选当前信息需要的观看方式。换景应增加可见信息；同张图的反复裁切、同一模型换背景旋转，都可能没有推进内容。不要给每节固定配齐“全景—整体—细节”。

[USM的三空间案例](https://www.usm.com/en/stories/usm-in-three-living-spaces)以相同蓝色构件重组不同家具。实屏儿童房中，书、玩具、门板与柜体共同交代使用；老建筑中横向展开的柜体与周围陈设建立关系；新住宅中开放构件让环境透入。可以学习“保留可追认的材料，改变配置及使用关系”，不能据此认定三组图片都遵循同一景别顺序。移到新项目时，先说明保留什么身份、每段多让人看清什么，再决定图片数量与排布。

[Feixen的Westbund案例](https://www.studiofeixen.ch/westbund-25/)由作者说明手势与循环的身份概念，页面展示其进入建筑、海报、衣物等媒介。可迁移的是某种形态/动作在不同载体上继续被辨认；具体渐变、字体、双色并排与循环形式都不是通则。信息工具或多作品档案可能更需要稳定查找与比较，不应把海报表达扩散到全部文字和操作。

先检查材料本身能否支持所说的内容。要表现收纳，开口、门板与放置关系须可见；要表现透光，光线与表面须有相应依据。示意几何可以解释关系，不能冒充已完成的产品/材料效果。手机若把两张图缩得无法辨认关键部位，可重新排序、改取景或给放大入口；并排本身不是必须保留的身份。

参考同样可能有响应式代价：正文被裁切、并排图缩小后细节难辨都要在当前作品检查。学习材料与观看关系时不把来源整体背书为响应式范本；研究画面不进入生产素材包。

## 权利逐项核对，研究与生产分开

[AS-04](conditional-design-rules.md#as-04)：以每项资源的实际来源条款确定可保存、修改、商业使用、署名与再分发范围。仓库源码许可不能代替图片、视频、字体、纹理、环境图、模型、音乐、商标和嵌入第三方内容的许可。公开可看、免费阅读、可下载、可私人研究和可生产转用不是同一授权。

| 研究来源示例 | 可支持的边界，仍需按使用时具体资源核对 |
|---|---|
| Apple AirPods / Vision Pro | 归档原创分析、链接与自绘结构；不转存商业原图/影片作为成果素材 |
| Devouring Details 免费页 | 免费可读不等于原文、截图、组件或付费内容可再分发 |
| model-viewer 示例 | 代码 Apache 2.0；页面分别列模型 CC-BY 2.0、CC-BY 4.0、CC-BY-NC-SA 等，逐模型核对 |
| Bruno Folio 2025 | 代码 MIT；现场音乐另述 CC0；缩略图、品牌等权利不因代码许可自动成立 |
| OP-1 / Six N Five / FutureDeluxe / Pixar / Spline / Lusion | 接受原创研究，不提取商业原片、模型、纹理、角色、商标或私有资源作为可用素材包 |

以上用于说明按资源核权的边界，不代替任何具体资源在使用时的许可核对。没有核实的云复制许可保留为未知，不把未知写成“已找到禁止条款”。新任务要转用具体资源时读该资源当前官方许可；无法确定时换成授权明确的候选，不因研究已经完成而默认放行。

## 建立可回溯的轻量素材表

[AS-05](conditional-design-rules.md#as-05)：每项素材至少保存下面字段，按当前任务汇成一表，不为每次裁切另写长报告。

| 字段 | 内容 |
|---|---|
| identity | 稳定 asset_id、文件身份/版本、原始文件摘要（可取得时）、类型 |
| provenance | 来源 URL、作者/权利方、访问日期；用户提供/生成/拍摄身份 |
| rights | 具体许可和证据链接、用途限制、署名、可修改/商业/再分发/云归档范围；未知明确写 unknown |
| role | 对应页面/章节、内容职责、是否是证据/装饰/产品事实 |
| composition | 尺寸/时长、主体与安全区、桌面和手机裁切、色彩/声音/字幕信息 |
| derivation | 原件指针、处理版本、裁切/压缩/调色/字幕/生成步骤与版本 |
| delivery | 本地/云端允许范围、生产文件路径、传输体积及验收状态 |

授权原件与处理版本分开；不将处理版覆盖原件。无法保存受限源文件时，只留允许的链接、原创观察与限制，不镜像商业库，不把本地研究截图混入发布包。哈希证明文件身份，不能证明许可、视觉质量或运行正确。

[AS-06](conditional-design-rules.md#as-06)：关键页前清掉会改变判断的假素材：不得用低质占位图通过审美交审，也不能把待授权资产藏进打包结果。按项目实际选择合适编码、尺寸/质量版本与加载顺序；先保证首个有意义内容，再按需加载后续媒体。优化后实际比较细节、字幕、颜色、透明边缘和声音，检查延迟/错误与低速加载。

对有声音/信息的视频检查静音文字、字幕与控制；对模型检查材质、贴图、尺度与替代说明。记录测得体积与运行结果，不虚构统一“必须4K60”、帧率或节省比例。生产发布表只列真正获准且当前使用的资源；代码检查通过不能替代素材许可和实际画面检查。
