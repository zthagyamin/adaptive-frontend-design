# 品牌编辑

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

先确定编辑立场：谁在说、主要对象是什么、材料能让读者看见什么、希望如何读完。刊名、期名、作品名、正文、题注、出处与工具各有职责；按目标语言检查实际字形、长度和断行；中文及混排时一并核对对应字形关系。

素材先承担内容，再承担气质。解释环境、人物情境、表面细节可能需要不同观看距离；没有所需画面时改稿或换素材，不靠文字补造图像事实。跨地点照片可并置，但不要暗示同一次实拍。作者、来源、许可和修改说明与使用资产对应。

先选承担主要内容的区域，再协调其他区域的视觉重量。图像面积、标题分量和空域根据叙述关系变化；后段特写或刊末不应仅因容器较宽就获得无意的主导重量。用于比较的内容保留相称的重复语法，不为每节不同而随机换布局。

正文与照片间的距离应支持对应关系。使用一组可解释的对齐参照与组内／组间距离；页面加了宽度上限后，再看内部以vw计算的间距是否仍符合实际版心，别让宽屏下的相对距离继续无界增长。

同一页需要明确章节转换时，先用标题、位置、尺度、短标记或有内容理由的边界；选择适合本题的一种共同语法。不把细长线、方框、去框、黑白或某套字库定成编辑类的默认答案。

注释层按实际内容建立，不因“展览/研究/编辑”自动添加英文编号、刻度和微标签。正文和主要说明保持可读，必要出处与标记再退居辅助位置；用虚弱横线和细小浅字反复填出层级，可能使不同题材仍共享同一套外观。处理整体同质化时回到[整体视觉语言](global-visual-direction.md)比较主导关系。

实看完整关键页及窄屏：主内容能辨、图注不串、目标语言的文字可读、必要内容不被裁掉，少量工具有反馈且不打断阅读。按当前内容调整宽窄顺序和取景，不只缩桌面。

Agent核验实际画面与路径；本人评价完整页气质、主次和阅读连贯性。仅视觉接受就只记录视觉接受。单一作品可接受支持本题的局部迁移，不证明所有品牌都应采用相同比例或审美已经稳定提升。

字形、图像／空域和宽窄重排遇到具体制作问题时，按需查看[设计基础](design-foundations.md)对应部分；实际素材转用与衍生处理再看[素材与来源](media-and-assets.md)。
