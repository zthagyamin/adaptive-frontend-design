# 实时 3D 与交互空间：对象、相机和语义界面共同工作

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

实时空间条件方法；当前对象、构图、输入与失败/备用路径必须在作品中验证。技术资格与审美接受分开。

美术与技术分别检查：输入、对象与状态成立，不代表高质量几何、材质细节、光照层次、场景构图、景别衔接及手机艺术方向已经完成。真实3D资格、复杂技术或未经连续验证的“流畅”不能代替视觉判断；需要以当前完整构图和动态证据判断效果。

用于需要真实对象查看、空间操作、可探索世界或用户推进的空间叙事；不因画面像 3D 就启用。先完成一条可运行的关键路径，桌面与手机同时设计，按[代表画面检查与扩展条件](composition-craft.md#代表画面检查与扩展条件)实看后推进；审核等待条件由该处统一维护。补充条件、代价与验收见[条件规则补充](conditional-design-rules.md)的 `RT-*`；实现建议与源站观察分开。以下保留对象/媒介与案例判断；跨段状态、完整取景、时钟和阅读返回由[场景连续性](scene-content-continuity.md)维护，渲染资源由[Three.js工作流](threejs-workflow.md)维护，交付证据由[运动验收](motion-language.md#正常速度观察与录屏)维护，不另设相同规则。

## 先确认媒介与任务

明确采用 Three.js，或要把本页的实时对象、镜头、物理反馈落为代码时，按需读 [Three.js 实施与验收](threejs-workflow.md)。它补充资源、色彩、状态与实际验证方法，不替代本文件的内容和构图判断。纯屏幕空间 shader / 2D 光效在该参考中单独选路，不因此追加空间漫游、GLB、碰撞或自由相机。

[RT-01](conditional-design-rules.md#rt-01)：资格依据应是实际输入引起相应的几何、视角、材质、光照或空间状态变化。canvas、模型标签、poster 消失或看似立体的截图均不足。产品查看器需实际旋转/切换对象/选部位；空间故事可以是用户驱动的镜头与场景变化，不强迫拥有自由相机。记录具体成立的能力。

| 公开参考 | 可研究的能力关系 | 不能据此保证 |
|---|---|---|
| [model-viewer Annotations](https://modelviewer.dev/examples/annotations/) | 对象切换、尺寸、材质、热点和视角如何相互对应 | 新作品的全部触屏、AR、上下文恢复或总览返回 |
| [Bruno Simon](https://bruno-simon.com/) | 角色、镜头、空间物件、地图和作品阅读的输入分工 | 任意新世界的实体手机操作或持续帧率 |
| [Lusion Storybook](https://exp-my-little-storybook.lusion.co/) | 用户推进章节、镜头、对白与场景状态 | 自由产品查看能力；无video标签也不能单独证明实时几何 |

[Spline](https://spline.design/)等工具可按当前任务研究，但能力概述不能代替实际项目验证；未经实测，不承诺自动低电量检测或转影片。

## 让真实对象有正确的尺度、材料和光

[RT-02](conditional-design-rules.md#rt-02)：先写对象合同，再追求效果。

| 对象合同 | 实现与检查 |
|---|---|
| 几何与身份 | 模型版本、朝向、原点、包围范围、可交互部位、必要细节；不要以近似装饰形状替代任务对象 |
| 单位与尺寸 | 模型单位、现实尺寸、测量参考点和显示单位一致；尺寸线来自当前对象，换模型不能残留旧值 |
| 材质 | 按主体确定金属/塑料/皮革/玻璃等角色与粗糙度关系；检查贴图、法线方向、透明层和色彩处理，并在最终尺寸的总览与局部辨认材质差异 |
| 光照 | 先保证轮廓与结构可读，再决定环境光、主光、反射与阴影；黑色产品不沉没、白色产品不糊边，辅助效果不竞争主体 |
| 内容事实 | 型号、部位名、功能与规格出自授权资料；视觉换色不能伪装已测材料性能 |
| 可交付资源 | 模型、纹理、环境图、字体与声音分别有来源与许可；体积/解码负担纳入预算 |

先以中性照明核对模型，再形成符合品牌的光线主线；这是实现起点，不是标准光强、材质值或几何预算。已有几何、贴图或材质参数仍可能呈现为难辨的平块；依据实际画面定位表面细节尺度、几何边缘、布光或取景问题，再决定补制或调整。不要给所有任务统一高反射金属或景深。技术文档可保持朴素 UI，绘本可用风格化自然，作品集可用玩具世界；通用原则是对象可辨认、关系一致。

换模型时让材料、尺寸与标注联动；风格化自然可由水、植物与角色构图建立。不能从截图反推出实际shader参数或真实物理精度。

## 先安排对象、文字和空域，再定镜头

[RT-03](conditional-design-rules.md#rt-03)：为总览、局部、选中、展开、不同对象和手机分别确定取景范围。相机目标、距离/视角、近远裁剪与模型范围一起检查；保留必要轮廓、尺寸、热点与说明空间。窄屏可改相机或构图，不只把桌面 canvas 缩窄，也不为了填满屏幕任意截掉主体。

留白有具体职责：对象周围用于轮廓/旋转/标注，路径空域用于移动和地点区分，天空/墙面可承载叙述，安静面板支持阅读。记录它延长了多少行动或阅读距离；没有必要的道路、空域与滚动不因“沉浸”而自动成立。

大模型可能超出可见区，提示、角色信息、音量和署名也可能彼此竞争。验收直接看像素中的裁切、遮挡与可读性，不能只验证 `scrollWidth`；模型与动作不能因画面放大失去关联。

## 热点负责空间指向，DOM 负责语义

[RT-04](conditional-design-rules.md#rt-04)：短热点标识部位、尺寸或视点；长解释放在稳定阅读区。热点使用有名称的语义按钮/等价可操作结构，键盘和触屏可选；当前项、焦点与内容同步。提供文字清单或等价路径，不能把 canvas 变成核心事实的唯一载体。

对热点区分遮挡、屏外与未选中：背面标记按任务隐藏/变弱/转清单，不假装二维连线具有真实遮挡；碰撞时聚合、重新定位或使用侧栏，不只把所有标记变透明。细标签不会自动有足够命中范围，触屏检查实际选择而非只看视觉尺寸。

对象→热点→解释→返回总览形成闭环。近景需显式总览/复位入口，返回时恢复合理视角与所选对象。验收必须实际点击返回并确认全景与热点恢复，不能让用户猜手势，也不能用页面滚动误充相机复位。

## 探索、内容聚焦和返回是三种模式

[RT-05](conditional-design-rules.md#rt-05)：空间探索给地图/目的地或直接内容入口，显示“在哪里、能做什么”。聚焦作品后压低背景竞争，把作品、名称、角色与控制放在能读的位置。退出恢复及世界/阅读输入切换按[空间入口与正文](scene-content-continuity.md#把空间入口接到同一篇正文)处理。

把“下一张媒体”与“下一项目”的命名、状态和目标分开，不能只给无标签箭头。入口提示对应真实命中对象；不要出现“点击文字”却必须点另一对象才能进入的猜测路径。地图、目标、阅读和退出的当前对象保持一致。

适用于探索本身有价值的品牌/创意作品。求职者快速查简历、库存比较、支付或紧急信息，应给可直接访问的普通内容路径；不必把它们游戏化。手机也要能从明确控制进入/退出，不依赖 hover 或桌面按键提示。

## 多幕叙事与重播共用完整状态模型

[RT-06](conditional-design-rules.md#rt-06)：每幕写“当前问题、主体位置、相机、对白、可用动作、到达条件”。长说明和必须回看的内容补章节索引/上一幕或等价路径；下一幕不能在镜头与文字尚不一致时显示错误状态。减少运动路径保留情节与推进能力，默认版仍完成所承诺的空间表现。

重播复位章节、对话队列、镜头、角色、计时器、输入锁、结束层的类/样式和交互可见性；切换宽度/隐藏页签时也不能遗失结束控制。检查完整首轮→重播→完整结束，按当前风险穿插尺寸变化或中断；首轮结束成立，不保证第二轮结束仍成立。

## 生命周期、资源和触屏与美术同时设计

[RT-07](conditional-design-rules.md#rt-07)：将 idle/poster、加载、ready、active、暂停/离屏、失败、context-lost、恢复、销毁作为资源状态。只在可解释的加载状态展示等待；失败给重试和可读内容路径。退出或切路由时停止输入/循环/声音并释放本实例持有的几何、材质、纹理、监听和连接；共享资源按真实所有权释放。恢复后核对对象/相机/选择，不只重画 canvas。

先记录当前资源字节、纹理/模型复杂度、首个可操作状态的等待、交互时主线程/渲染负担，再以目标设备实测制定预算。按需求选择按需渲染、延迟载入非当前章节、降低像素密度/阴影/后期强度或资源变体，不能预设通用帧率、固定三角数或“低电量自动检测”。若提供手动质量档，要检查切换后的轮廓、材质与文字；正常版强表现不能因省事只交 poster。

这些生命周期和资源策略在当前实现中验证，不由源站表现推断上下文丢失、内存或低电量通过。若运行环境不能支持承诺的实时能力，说明差距与可审阅的替代方案，不能把替代影片标为实时通过。

[RT-08](conditional-design-rules.md#rt-08)：明确单指拖动、双指缩放、页面滚动、点击热点的归属。只有需要操控的范围捕获指针，处理取消/失焦/离开；不要全页拦截滚动，也不要要求用户完成多指手势才能退出。相机约束防止穿模、无限远离和失去目标，并给总览。

同步检查桌面、平板、390、320 与横竖变化；CSS 窄视口、触屏模拟、实体手机分开报告。除非实际执行，不称触摸惯性、双指、AR 或手机性能通过。运行验收包含旋转/部位/对象切换、热点与文字同步、进入→聚焦→退出、资源失败、减少运动、离屏恢复与销毁；适用项按当前路径选择。

最终交审：实际可运行关键页、完整构图与关键状态、实际观察和具体未测项。正常速度观察与按需录屏按[运动验收](motion-language.md#正常速度观察与录屏)；静态美术、实时资格、行为通过、性能观察和用户审美接受分别记录。
