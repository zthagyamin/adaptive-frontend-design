# 颜色、材料与界面分工

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

整体方向遇到配色不协调、素材进入后重心变化，或把强色误当原创时读取。以下公开来源说明颜色与材料的不同关系，不是可直接套用的六套主题；站点可能更新，采用前核对当前相关页面。

| 来源与观察 | 可影响的制作选择 | 代价及不能迁移的部分 |
|---|---|---|
| [HAY](https://www.hay.com/)：作品摄影/影片承担主要颜色，浅灰页面与深字组织不同物件 | 产品纹样或环境本身有信息时，先让媒体给出颜色及尺度，再决定外壳重量 | 依赖素材质量；不能把某张淡化中的图片当成原图色彩，也不推成所有界面都应中性 |
| [Aesop](https://www.aesop.com/)：所看主页暗木影片上使用浅字；商品阅读区较亮、文字和动作较深；礼盒图片切换后说明区保持 | 同一对象由陈列进入环境时，可以改变影像光线而保持阅读/操作参照；每种背景实际核对文字明暗 | 暖白、木色与琥珀是此案例的组合，不是新默认；单帧不能证明整段影片的文字可读性 |
| [Rijksmuseum](https://www.rijksmuseum.nl/en)：所看章节的大图带来不同冷暖色场，叠加文字及局部暗部处理维持辨认 | 图像承担场景时，可随内容换色而沿用身份参照；需要判断的是每张图与文字的关系 | 同样的浅字并不适合全部图片；大字、暗渐变或整屏图均有遮挡/裁切代价，需本题复查 |
| [The Met](https://www.metmuseum.org/)：所看首页让不同展览素材在共同阅读区域并列，红色参与服务/票务等机构入口 | 区分材料内部的广谱颜色与持续机构识别；不必把异质作品全部染成品牌色 | 当前观察不等于任何年代品牌规范均仍生效；红色机构识别也不等于所有站的按钮都应红 |
| [Pentagram](https://www.pentagram.com/)及[Design Doha](https://www.pentagram.com/work/design-doha-biennial)：网页承载层与作品颜色分工，详情由作者解释字形连接及色彩来历 | 有真实身份依据时，把概念、字形和材料关系一起迁移；网页可以清楚展示强表达作品 | 初始灰块和受许可阻断的视频不作为完成构图/运动证据；不照搬某个项目的颜色与字形 |
| [GOV.UK colour规范](https://design-system.service.gov.uk/styles/colour/)：官方将文字、链接、焦点、错误、成功等按用途组织，并限定变量语境 | 在多状态操作中保持颜色含义和其他识别线索；表达色与状态色分清使用语境 | 官方用途分类不代替新项目实际状态测试；该体系的具体色值不进入新项目默认 |

## 用到当前制作

先选定当前画面要突出的主体，再看素材、背景、文字和操作实际怎样共同占据画面。若颜色承诺了材料感却缺乏相应光照/细节，回到资产表达；若多处都在强调，先查职责及面积，不只挑“更和谐”的色名。对信息密集的工具、已接受的品牌或精确复刻，沿用任务要求，不为展示研究强加摄影舞台。

跨3D章节时，环境光和背景变化也会改变对象的可辨认颜色、轮廓与正文对比。按当前距离复看同一对象的材料特征和文字所需的阅读底；保留品牌/动作含义不要求所有场景同色。这是从上述静态/影像观察迁移的待验方法，不是实时渲染结论。

这些关系可以用于提出制作方案，不能自行给方案审美打分。“明显不同”或技术可读不等于视觉接受；当前画面仍需以真实材料和完整构图判断。来源与归属见[来源说明](../SOURCES.md)。研究截图与商用原始素材不进入生产包。
