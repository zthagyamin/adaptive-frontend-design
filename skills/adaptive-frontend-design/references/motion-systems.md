# 把 motion 做成可以参与的过程

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

当方案明确需要整页滚动编排、可扰动图形或共享对象展开时，读对应部分。三种是不同能力，不是每页必须配齐的组件。局部反馈无需升级成大场景；先按内容确定运动主体，再选实现。

本页提供三种动态的实现关系与常见故障修法；不是商业源站复刻，也没有跨题审美收益结论。色彩、几何、曲线数量、毫秒数和距离均不作为模板规定。

## 滚动编排：空间连续，信息有可读时刻

先画出开始、关键中间姿态、交接的关系：主体露出哪一面，镜头靠近还是绕行，文字此时解释什么，下一段从哪里接入。整体动态可以由主体尺度/方向、文字布局、色场或空间参照共同完成，不靠每段同一种淡入证明“有 motion”。选有内容意义的主变化，其他层有主次地支持它。

需要原生阅读时，用文档滚动范围提供进度，sticky 容器提供舞台。设段落文档起点为 a、可滚动范围为 d，则 p=clamp((scrollY-a)/d,0,1)；resize 或内容高度变化后重新量测 a/d。阈值启动动画、直接取 f(p)、加时间跟随是三种选择，具体区别见[运动语言](motion-language.md)。空间要停手即停时，从 p 直接求对象姿态、镜头位置与目标，避免每帧再 lerp 一遍。相机朝向和取景另按[Three.js](threejs-workflow.md)检查。

为阅读保留稳定区间：开场建立全貌，中段揭示关系，末段交出下一步。进度可以分段平滑映射，但距离须由可读内容和变化量决定；不要用很长的空滚动等待制造“电影感”。锚点、快速倒退、从页中载入都应落到同一进度的合法画面。

**停在任意中间位置检查正文。** 两段不同标题在同一位置随 p 交叉淡化，停住可能永远是双影。适用于单一正文位的一种解法是：p 选择当前语义章节，旧块立即退出可见/可访问状态，新块用有限时间完成短促入场；即使滚动停止，也把正文落定。空间仍随 p，文字由章节变化触发，不把两者误称同一个时钟。快速反向只让最新章节拥有正文；另一种方案可以让两段在明确分开的空间交接，前提是暂停处仍读得懂。

初次开场若独立于滚动，明确用户滚动如何接管，别让开场与阅读争用相机。需要让用户重看时提供显式重播；从当前姿态连续转出再进入，不强制跳回第一帧，也不定时反复播放。

## 指针与拖拽：决定哪一片材料在响应

图形表面的 hover 可以根据当前指针附近的距离产生局部排斥；drag 则可以记住抓取时的邻域，让同一片材料被拉伸。每帧重新按当前指针挑选受力对象，会让拖动看起来不断换抓取点。命中面保持稳定，只有图形子层移动；标题、按钮和阅读坐标不跟着逃走。

弹性表现可用每个图形点的位移 u、速度 v 与输入目标 g 推进，例如 `a = k * (g - u) - c * v`，再按秒积分 v/u。限制异常帧间隔，必要时细分时间步；它是可调的视觉模型，不是凭公式就能保证稳定的物理模拟。精确滑块、命中坐标与读数直接跟随输入，不能复用这类有意的弹性滞后。

松手是移除外力，不是重置位置与速度。若需要甩动，只用近期带符号输入速度有限补充当前状态，并使过旧采样失效；长按后释放不应借用很早的高速。回弹停止同时看目标误差与速度，低速也可能只是转向极值。受力下的静止平衡与释放后的归位分开判断，避免为省帧把尚未归位的形状冻结。

用 pointer capture 持有同一次输入，处理取消与丢失。resize/更换内容若要重建点阵，先清理旧 capture，再重建；如果选择保留手势，则把抓取坐标映射到新几何，不能只清空内部 id 而留着浏览器捕获。触屏横向探索保留纵向阅读和缩放；CSS 声明不能替代真机验证。

键盘按钮应驱动同一图形结果。减少动态可直接呈现一次静态形变与恢复，而非只让按钮缩放、图形不变。能力缺失时保留明确降级状态，后续偏好或普通初始化不能把它覆盖成“等待交互”。隐藏、离屏或被详情覆盖时停止推进，恢复时重置时间基准，避免补算整个离开时长。

## 展开与收回：同一对象，真实几何

入口和详情确为同一对象时，从入口图形的实际屏幕矩形走到详情中的目标矩形；图像身份不换，周边说明与底色各自配合。让视觉层脱离布局并保持统一坐标系，动画结束再落到稳定结构；不要把整个文字容器粗暴 scale 到目标大小。形变如果只是视觉复制层，隐藏原图时仍保留入口布局和操作语义。

以当前显示矩形和最新目标驱动位置、宽高与裁切；打开、途中关闭、再次打开都从当下接续。固定时间线和跟随器都可用，取决于本题是否需要连续改意；不要每次从预设 0/1 重播。具体连续值推进可参考[交互质感](interaction-craft.md)中的运动核，但它不负责对象身份、原生 dialog、焦点与布局。

切换到 B 后，标题、图样、可访问名称和返回目标也属于 B。关闭时收回当前 B 的真实入口，或者明确淡出回浏览位置；不能把 B 变成最初 A 的缩略图。保留原阅读位置与当前入口焦点，两者分别处理，焦点恢复避免再次滚动。

resize 会改变目标和入口的实际位置，重新量测后接续；长内容在窄屏允许内部滚动，图像与说明保留自己的高度。不要让可收缩的 grid 行把图像挤出行框并覆盖标题。控制应始终可达，关闭和改选不等待整段表现播放完。

## 用最短实际路径检查

先跑一次正常过程，再在最可能失败处停住或改意：滚动停在文字交界并倒退；拖出明显形变后松手并观察最终归位；展开途中关闭/改选，再返回当前入口。对实际涉及的尺寸检查重排和目标几何，不重跑无关场景。

实际输入、中间状态、静态截图、逻辑回归、连续原速观察和本人审美确认分别记录。截图能指出双影、遮挡和落点，逻辑检查能验证连续性/状态不变量，它们都不能单独证明舒适手感、真机表现或稳定帧率。把可操作完整页面交给用户，而非要求用户负责录屏、校准或替Agent排错。
