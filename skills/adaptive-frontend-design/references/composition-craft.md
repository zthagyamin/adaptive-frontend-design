# 把身份和比例变成可见的制作取舍

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

用于原创构图、跨作品同质化，或比例/疏密/分组反馈。目的与艺术方向尚未明确时先读[整体视觉](global-visual-direction.md)及[设计对话](design-dialogue.md)；已确定的局部修订直接处理，精确复刻遵守给定构图。

## 从材料里找形式，先排出能判断的东西

将主任务落实为可见关系：全貌与细节、并置比较、同一记录的重复、解释与对象、动作前后变化。先决定读者在哪里开始、为何操作、操作改变什么认识或结果，再安排内容单位和观看距离；不要先固定观看器或大标题舞台，再寻找用途。跨作品是否只是换主题/配色，按[四维对照](global-visual-direction.md#跨作品表达差异的实屏对照)判断。

用目标语言的真实标题、最长说明、当前素材和必要入口排出能判断的片段。只有关系仍难以判断时才比较简稿，不重新提问已确认的方向，也不为不同而随机换网格。

- **主内容是否先被看见？** 图像内部的亮部、对比和裁切可能压过标题；以实际材料判断，不只比较容器尺寸。
- **对象是否能承担说明？** 看轮廓保住轮廓，看局部给局部可辨面积；材料不足先补资产、改取景或调整主张。
- **解释与动作是否能找到对象？** 图注、数值、控制与受其影响的内容保留可追踪归属；长空程可能拆散它们。
- **身份与代价是什么？** 字形、标记或组图需有内容依据；大照片可能把说明推远，紧凑列表可能削弱观看，按当前任务裁决，不用固定面积比例评分。

例如织物档案，辨认经纬连接适合清楚近景与稳定比较标记；看衣片和身体关系则需要完整造型。题材本身不自动推出米色、细衬线或做旧纹理。

## 代表画面检查与扩展条件

方向比较帮助选方案；代表画面检查回答已选方向能否兑现。新建或整体改版明显依赖主素材、复杂构图或持续3D时，先把真实文字、必要动作、实际字体、成稿意图的主体、光线和材质放进最终显示尺度的运行画面。可以是一段，不要求多套高保真稿，不新增每轮本人审批。

代表性由任务决定：品牌开场不代替查找、比较、日程或长文。只为当前确需、会改变素材/密度/操作选择的任务保留代表片段，走正常路径与途中改意；已接受页面的小修只复查受影响关系。

先判断轮廓/细节、材料与说明、主内容与阅读各有位置。主体仍像示意体、材质沉没或图文争抢时，先修资产/灯光/取景/构图，再扩展依赖它的章节；其他明确部分可继续。技术可运行与美术可继续制作分别记录，不能用几何全入镜代替构图判断。

持续3D还要实际走一次关键内容交接：说明出现时，相应细节已或正在清楚入镜；稳定阅读时画面不继续夺取注意力。技术状态、无人能实屏的缺口及扩展依据分别记录，不补写通过。[音箱示范](representative-example.md)是具体例子，不提供通用外观或镜头模板。

## 用疏密和主次组织区块

收到“挤”“没有呼吸感”“散”“全是块”的反馈，先定位主内容、同组联系与真实任务转换。留白机制与代价沿用[设计基础](design-foundations.md#每处重要留白都要付得起代价)，这里只按现象选择修法，不另设全站参数。

| 当前可见问题 | 优先核对与修订 |
|---|---|
| 有空白仍拥挤 | 标题、图像主体、强色场和工具是否同时很强；先确定主次，再选一处调整面积、重量或位置，保留正文可读性 |
| 每块都太近或太远 | 标签—输入、图—图注、标题—段落的归属是否连续；把停顿放在真实任务/话题转换，不按固定倍数分配间距 |
| 去线后归属模糊 | 邻近、对齐、语义标题、字形或局部底色是否足够；保留服务比较、交叉读取和操作范围的线，底色也会增加边界与重量 |
| 大块空洞或图文距离异常 | 核实际display、盒尺寸、百分比高度、min-height、媒体比例及加载状态；先修失效约束，再判断负空间 |
| 窄屏字列变碎或长空程 | 重排栏位、工具与对象或容器占幅；不以缩小正文、压薄字重、照搬桌面间距补救 |

紧凑比较、目录/筛选和连续正文各有合适节奏。密集表格不逐行拆成章节；让任务转换有停顿，也不按固定“疏—密—疏”轮换组件。修后在受影响的相邻区段和宽窄窗口复看：先看谁、归属是否清楚、能否一起比较、后续入口是否被无理由推远。

同内容的局部前后状态足以校对，不强制新增多方案开关或审批。多项比例与间距一起改时，按组合结果判断，不把感受变化单归因于一个参数。去线后仍可能拥挤；先检查主次、归属和真实尺寸约束，不把增宽、去底色、缩图或换字体当通用配方。

## 在完整阅读路径里校正

把首、中、末接成认识顺序：每段新增什么认识、依据或有意的情绪转折，读者如何继续或返回。反复放大同一主张时，合并或补内容比换组件有效；导航和身份的合理重复可保留。

观看距离、文字密度和裁切随问题改变。全貌、局部和使用情境需要不同材料；受控裁切应帮助当前认识，并能在必要处补全信息。说明或工具被推得太远时，重排它们与对象的关系。宽窄屏允许改变顺序、取景和展开方式，不以桌面坐标为验收目标。

例如[OP-1](https://teenage.engineering/products/op-1)从整机转入微距、界面与规格，媒介变化对应理解对象变化；不能推成所有产品都要长页、微小注释或相同节拍。短窗口中的尺寸故障按本页诊断核对，不照搬来源数值。

若参数微调后整页仍别扭，回到内容顺序、主资产和骨架定位；局部问题只改相应部分，结构问题才提出结构修订。模型或组件已经写好，不构成保留其主导地位的理由；已有明确目标和授权直接推进。

## 依据与边界

本页提供可迁移的制作方法，通用机制由[设计基础](design-foundations.md)维护，来源与归属见[来源说明](../SOURCES.md)。每个新作品分别记录实际观察、用户接受和未测范围；不建立通用风格、比例或审美收益结论。
