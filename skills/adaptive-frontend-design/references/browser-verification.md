# 把验收落到真实页面与原路径

> 公开分发版：本页为项目实作中的方法归纳，来源与第三方许可见[来源](../SOURCES.md)。

用于包含异步保存、详情/历史、隐藏或重绘控件、持续动态和资源加载的实现或回归。局部改字沿用已有证据，不为每个任务建立完整测试平台。使用当前宿主支持的浏览器接口；仓库维护者可用CI补充回归，使用此Skill不要求安装特定框架。

## 先固定要证明的事

记录当前源版本、运行入口、真正选中的页面与实际生效尺寸，再选覆盖当前承诺的路径。控件存在、HTTP成功、数学测试、截图、真实输入、连续观察和用户接受分别支持不同结论。

| 当前风险 | 应走的路径与实际结果 |
|---|---|
| 导航与阅读接续 | 直接打开、刷新、关联阅读、前进/后退、关闭；地址、正文、来源和可见焦点一致 |
| 异步提交 | 等待期间结果尚未确认；成功、失败重试、重复提交和冲突后改选；按响应保留或更新真实数据与输入 |
| 隐藏/重绘当前入口 | 先完成新状态和可见入口，再交接焦点；检查原生关闭事件和迟到回调是否再次覆盖它 |
| 直接操控与取消 | 真正的指针路径和键盘路径分别走；快速改意、释放、失焦、尺寸变化和重进作用于合法的当前输入 |
| 媒体与模块加载 | 实际解码或执行、正确响应类型和依赖图可达；失败时保留未依赖它的内容与退出，重试不伪装完成 |
| 窄屏与减少动态 | 重排后仍能看见对象及结果、执行核心动作、退出和返回；窗口模拟不记为实体触摸通过 |

先复现最短失败序列，定位在哪个交接点失配，修后从同一入口复走。返回位置与焦点分别量测；元素有矩形不代表它在当前视口或内层滚动区可见。共享同一DOM视图的封面、目录与阅读来源仍可能有不同导航意图。

## 自动回归与实际体验各自留证

自动检查应操作真实页面和生产事件处理，断言用户看见的结果；纯函数、桩和结构检查继续保留，但不能替代浏览器。先观察针对缺陷的失败，再修复并检查受影响路径。失败截图与trace有助于定位，截图差异本身不判定美术好坏。自动滚入视野或只设置输入值可能与普通操作不同，关键疑点回到支持的原生输入核实。

动画任务以正常速度操作必要中段、改意和释放；静帧与状态码不证明连续手感。工具只能取得抽样时注明范围，仍交可运行体验，不把录屏或校准变成用户的新前置工作。真实触摸、读屏和设备性能按实际可用能力记录。

自动可访问性扫描用于发现名称、结构和对比等常见缺陷；另走键盘、错误说明、缩放与返回。可访问名应对应可见动作；测试严重问题不能通过删除必要内容或放宽断言消失。自动通过不等于完整可访问性认证，见[官方说明](https://playwright.dev/docs/accessibility-testing)。

## 资源与性能读真实数据

按当前显示任务区分原件、显示派生物和按需近看资源。记录实际请求字节、首个可操作等待、布局变化与活动帧；同环境多次观察，再比较优化前后。文件体积减少不单独证明交互更快；一项示例的预算不成为其他网站的定律。

持续场景的诊断应来自实际渲染器、计时和资源释放后的值。重进多次比较同质量档的基线，区分实例资源、引擎缓存和驱动内存；rAF次数、帧间隔或CPU提交耗时各自不等于GPU完成时间或持续流畅。诊断不能预填合格值，也不应每帧改写整段DOM干扰被测体验。

## 输出最小而可复核的记录

交付运行入口、指定版本、做过的动作、观察结果、必要画面及未测项；初版、作者修订、协调者修订与用户反馈分开。将具体失败归纳成有适用条件的方法，不把示例的颜色、控件外形、参数或框架变成默认模板。

框架维护者可按[Playwright CI](https://playwright.dev/docs/ci-intro)和[测试服务器管理](https://playwright.dev/docs/test-webserver)构建可重复检查；采用其他已有工具时保留相同证据边界，不因工具名字判断成品通过。
