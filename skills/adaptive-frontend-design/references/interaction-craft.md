# 让输入、画面与抵达连在一起

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

用于转场、翻页、指针反馈、拖动和滚动的制作或调试。普通状态反馈可沿用现有组件；不为“高级感”强加惯性、遮幕、3D或自定义光标。

## 先决定这次动作是什么

| 内容关系 | 起点和抵达怎样对应 | 实施时的关键选择 |
|---|---|---|
| 按压、启用、选择 | 输入立即得到局部反馈，真实结果决定持续状态 | 受理不等最终动画；不拿假等待装饰即时操作 |
| 同一对象展开或回收 | 同一件内容从入口来到更大的观看位置 | 从真实入口和当前图像几何出发；中途关闭从实际画面返回 |
| 不同对象换件 | 新内容有自己的身份，旧内容让出观看区域 | 依据对象关系选择切换、短位移、淡化或其他手法；不把A缩回B的缩略图 |
| 连续拖动、滑块、精确选点 | 对象与读数明确跟随输入 | 核心输入直接映射；延迟只给确有目的的次要表现 |
| 指针装饰、吸附、观察镜 | 反馈跟着一个真实关注点，离开能退场 | 位置与取样共享同一坐标；命中区稳定，不追着用户逃走 |
| 章节导航或滚动联动 | 阅读抵达真实章节，空间与焦点可理解 | 优先原生滚动；需要定制过程时明确唯一滚动所有者、取消和抵达 |

这些是选择关系，不是效果配额。图片不同可以直接交接，同对象也不一定需要飞行；看当前任务是否需要解释入口归属、空间或方向。

名称先辨清是当前值、选择身份还是下一次动作，并让选中、图标、文字及可访问状态表达同一事实。持续开关可用稳定名称配合开关状态；若标签改为下一次命令，可另给当前结果，不必同时伪装为含义相反的选中状态。例如动态开关、声音命令与当前配方各有作用范围，不强制所有控件使用同一种实现。

## 先做一条完整切片，再扩展

把一个入口、真实内容和返回接起来，别等整页完成才调运动。按正常速度走“进入→变化→抵达→返回”，再在变化途中改选或关闭。检查输入是否受理、注意力跟住谁、中段会不会空等或看成另一个对象、落点是否清楚。

按现象改一个原因，避免所有参数一起调：

| 看到的现象 | 先检查 | 对应修订 |
|---|---|---|
| 点后先等一段才开始 | 解码、等待旧动画、串行退场是否阻塞 | 受理先可见；最新意图可替换旧意图；保留必要异步边界 |
| 改选时突然停住再起步 | 是否从预设起点重播、速度归零、CSS与JS重复平滑 | 从当前显示状态接续；需要延续惯性的运动保留可用速度 |
| 到点突停或过冲 | 位移大而制动太晚，或新目标已近却沿用过大速度 | 根据剩余距离制动；先修收束，不直接延长全部时长 |
| 框跟上了，内容还在滑 | 框、取样、图内裁切是否各算一遍不同坐标 | 一套坐标驱动画面；把object-fit/position纳入映射 |
| 每个动作都像演一遍片头 | 确认、换件、靠近、返回是否共用同一长时长或幕布 | 重新按关系分工；无内容交接意义的遮挡和等待可以去掉 |
| 快速鼠标失败但键盘通过 | pointerdown取消、默认滚动、焦点滚动是否抢所有权 | 查真实事件顺序和实际scrollY，分清“取消旧过程”与“新过程没启动” |

“软”也可能只是慢。先让用户能持续改意，再在内容需要的范围内试起动、经过和收束；不把弹簧、某条曲线、某个毫秒数当品质保证。

## 改选从当下接续

动画状态至少区分当前显示值、当前速度、最新目标；异步内容另带对象身份与请求版本。

- 单一标量跟随可以选CSS/现有库；具体API是否继承速度要核对。固定时长的叙事适合时间线，不强改为跟随器。
- 需连续跟随时，以帧间秒数推进状态；更新目标不重置当前位置。若新目标很近或位于边界，制动可以主动改变速度，此时不能声称全程速度连续。
- 数值输入、指针命中和实际拖动默认直接映射；不要把为了装饰的滞后写回用户输入。二维框与放大取样共享过滤后的x/y，而非各自加transition。
- 单一对象由一个驱动器拥有transform或scroll。逐帧写transform后再加CSS transform transition，会把已经平滑过的轨迹继续拖慢。
- 关闭/重入先使旧请求失效；解码、动画完成回调都检查当前版本。内容未载入保留当前可读对象，并给可重试路径。

延迟筛选/提示也有所属的表单或页面，不只是网络请求才会过期。若任务需要返回最新查询，可把合法查询身份先保存，再延后次要结果渲染；离开、清空或替换宿主后，旧回调不能继续读已销毁节点。重置尽量保留不变的表单/输入，只更新变化结果；会移除当前焦点时给出仍可见的合理目标。用“输入尚未落定就切页、返回、清除”实际检查，不只等所有延迟结束。不为此统一引入状态库或固定防抖时长。

**取消哪个输入，由输入的归属决定。** 指针捕获取消、布局尺寸变化、逻辑保持和整页失焦不是同一件事。反馈文字也可能改变容器尺寸；对象身份与模型坐标中的目标仍有效时，不应因一次布局通知就取消DOM或键盘保持。真正失效的捕获仍要释放；失焦、离屏与切换的范围按本任务决定。以实际事件顺序核对，不通过禁用观察器或忽略取消事件掩盖原因，也不强制所有项目建立同一套状态框架。

需要独立于框架的小型标量跟随时，可复制[运动核](../assets/motion/retarget.mjs)到当前项目。它只有临界阻尼推进和按剩余距离限速；不管理DOM、焦点、生命周期、队列或完整交互，也不是必须采用的依赖。`omega`单位为每秒，示例参数只是起点。

```js
import { criticalStep, brakeForTarget } from './retarget.mjs';
let visual = { position: 0, velocity: 0 }, target = 0;
function retarget(next) {
  target = next;
  visual.velocity = brakeForTarget(visual.velocity, target - visual.position, 18);
}
// 在当前项目已有的帧循环内；dt单位为秒。隐藏页恢复时先重置帧时间。
function frame(dt) {
  visual = criticalStep(visual, target, Math.min(dt, 1 / 30), 18);
  // visual.position驱动一个表现；输入值与对象身份另由真实状态持有。
}
```

若直接保持旧速度，新目标在眼前仍可能冲过头；若每次都清零，又会在每次改意时明显刹停。选择取决于剩余空间和动作职责。硬边界拖拽、碰撞、循环角度、路径/相机插值另需对应规则，不用这个标量核冒充完整物理或空间解算。

## 换件、返回与滚动的几处易错点

**换件。** 短距离重叠只是选项。取当前图层的真实opacity和transform再接续，不能取消后强制设成1或回到固定起点。新目标已在过渡层中时可以复用；结束只留下当前对象，清掉旧动画和临时层。标题、图注、索引在真实对象切换时一致更新；文字同位重叠可减少重叠量，别把双影当高级。

**返回。** 缩回入口只在当前内容与入口是同一件时成立。换到B再关闭，不能把B变形成A的缩略图；可淡出回到原浏览位置，或另设计真实B入口的归属。焦点恢复使用preventScroll或等价能力，避免另一次默认滚动改变返回位置。关闭过程中再次输入由当前语义决定，不留永久禁用或锁滚动。

原生对话框的关闭事件可能稍后才到达；若当前动作立即聚焦，而旧关闭处理又回到默认按钮，最终焦点仍会错。让一次关闭的焦点交接有明确所有者，等当前状态/重绘完成后解析实际来源；新操作使旧交接失效。来源被隐藏或移除时，选同内容的可用入口，并核对视口和内层滚动裁切。不能为保持旧scroll而把焦点放到屏外标题；相关实测顺序见[浏览器验收](browser-verification.md)。

**滚动。** 章节属于真实文档时保留原生阅读。确需自定义动画则由一处持有位置与目标；滚轮、触摸、拖滚动条、键盘、history与resize按任务取消或重算。比较浏览器实际位置和自己最后写入位置可帮助识别外部滚动，但阈值由实际舍入和布局检查决定，不照抄其他作品的数值。不要每个scroll事件都取消自己，也不要压回用户的新位置。

**指针。** 观察镜的框中心和取样必须来自同一当前位置，基于图像实际contain/cover尺寸、裁切偏移和视口坐标换算。离开、滚动、失焦、关闭页面、触屏分支能退场；窗口边缘限制不能把关注点映射到错误细节。镜内内容应帮助观察，不遮住仍需点击的对象。

3D控制显示已接管却拖不动时，先查实际命中层。例如装饰渐变层覆盖canvas时，按钮状态可能成功、相机却不变，elementFromPoint命中的是装饰DIV。仅装饰层可设为不接收指针，再用同一鼠标序列检查视角。不能以按钮状态或程序事件代替这条路径，也不能给承担真实操作的内容一律设置pointer-events:none。

## 怎么验证，哪些不能据此声称

使用真实入口和支持的输入接口。先单次，再途中反向或改选，再关闭/返回；把出错的最短序列保留为回归。鼠标、键盘、触摸是不同路径，程序click不带pointerdown；自动定位点击也可能先scrollIntoView。减少动态应保留核心结果，但实际环境未测试就写未测。

离散截图与坐标可以支持落点、遮挡、取样和状态；连续手感需正常速度实际观察。原速观察与按需录屏统一按[运动验收](motion-language.md#正常速度观察与录屏)；片段须对应当前源码，交可运行页并说明观察范围，不要求用户新增录屏或校准。数学测试只证明运动核的性质，不证明动态美感、帧率或用户接受。

本页的运动核和状态组织是可按需采用的工程方法，不声称商业源站使用了同一算法。数学性质、正常速度手感、持续性能和用户接受分别验证；来源与归属见[来源说明](../SOURCES.md)。
