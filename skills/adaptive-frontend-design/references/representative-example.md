# 概念音箱：从整体到控制细节

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

这是用于讨论素材、构图和持续3D的构造例子，不是默认模板，也不声称附带可运行产品或已完成新效果验证。它没有声学性能、量产工艺或真实商品主张；示例无需商业媒体。

第一段认识机身、格栅与支脚组成的轮廓；第二段看顶部旋钮、标记与机身的连接。它们需要不同观看距离；文字密度和场景占据范围随问题改变。阅读说明时保留对象身份和入口，关闭后回到可见的同内容位置。

## 把内容变成制作链

| 内容 | 资产与画面需要什么 | 接续与检查 |
|---|---|---|
| 整体形体 | 有厚度、倒角、格栅和底座的完整机身；目标语言的真实标题与必要动作同屏 | 轮廓、接触感、标题与主体各有位置 |
| 顶部控制 | 旋钮、凹入顶面与可辨标记；近看不必塞入全部机身 | 总览进入细节时看中段，抵达后正文稳定可读 |
| 设计说明 | 正常阅读尺度的正文，内容与当前对象相符 | 阅读接走输入，返回恢复身份、合理取景与可见焦点 |

## 整体与局部各有不同依据

先认识整体时，轮廓、格栅、支脚和旋钮应能辨认；标题与说明不能压住这些依据。可以并置，也可以前后组织；不把左右分栏当必要形式。

构造一个反例来检查判断：把主标题放大并移到机身上，再缩小必要说明。若格栅和轮廓被遮挡，问题在于本段要看的依据与阅读争抢，不能仅称“标题太大”。修订归属、位置与重量，不把所有叠字、强标题或半透明承载列为禁令；这种构造比较也不是历史失败或A/B收益实验。

当说明转向旋钮，镜头换到更高、更近的位置，让刻线、滚花与顶面关系成为可见依据。机身可以受控裁切，正文移到不挡控制的位置。只改文字却保留正面远景，无法兑现顶部结构说明；资产没有该结构时，先补制或改主张。

## 窄屏重排与完整返回

在相关窄屏重新安排标题分行、导航、文字与对象，不把整页同比缩小。需要完整比例时保住两侧机身；需要部位时允许近景，但能回看全貌。图像与说明占位、控件命中和固定层遮挡分别检查；CSS窗口模拟不代表实体触屏通过。

用真实入口走总览→顶部细节→阅读→关闭→继续；途中改选、拖动与宽度变化按当前实现验证。相机接管保留位置、朝向、视锥和控制目标；返回焦点需要可见，不能只保留旧scrollY。

中性底色、任何具体配色、字形与段落数量均是可以改变的题目选择。可复用的是“内容要求什么依据、素材和取景怎样兑现、阅读怎样返回”的方法。静态画面、连续运动、实际输入、实体设备与用户接受分别记录。
