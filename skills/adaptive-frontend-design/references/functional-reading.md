# 功能阅读

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

从真实阅读任务确定正文、示例／代码、比较、帮助与当前操作的关系。读者需要对照时把对应对象放在合适距离；必须依次理解时保留连贯阅读，不把并置或卡片当作固定答案。

语言／技术／对象选择、示例结果和说明指向同一上下文；选项变化后核对真实内容及状态，不能只检查颜色或选中标志。代码和宽内容缩窄时保留可达路径，不以整页隐藏溢出掩盖裁切。

进入参考或展开局部后，返回能继续同一对象。保留最新合法状态；需要恢复位置时识别真实滚动容器、内容身份与当前版本。普通浏览器行为已经足够好时保留，不强制叠加语义恢复。对象或锚点失效时给出可用退路，不默换对象或回写旧值。

把受理、等待、完成、失败与继续路径说明白；控件按真实异步结果更新。一个任务避免重复而含糊的完成入口。选值、保存成功、内容正确与用户效果反馈是不同观察。

用一条完整正常路径及受影响的关键失败／返回分支核验；键盘、窄屏和实际状态按本题需要覆盖。真实作者跨文档修改及维护速度另需真实任务证据，不能由读者端页面或模型推断宣称提升。

需要密集比较、代码／表格或阅读工具的具体编排时，再查看[场景方法](style-archetypes.md)中SCN-01—05相关部分；不把该参考全篇变成每次必读。
