# 动作控件：按职责、页面环境与状态选择表达

> 公开分发版：相对原项目指导做了去标识与可移植性改写，来源与第三方许可见[来源](../SOURCES.md)。

控件形式需要选择、整体改版或被指出同质化时读取。已有明确设计的小修沿用当前语言；新网站仍先按需求对话确定任务与方向，不让用户替Agent挑完每个按钮形状。

## 先作六个相连的决定

1. **动作改变什么？** 前往资源、执行命令、展开说明、选一个值、切换设置与连续施力是不同工作；先写清结果和作用对象。
2. **此刻有多重要？** 看当前动作组的主次、使用频率、决策成本和是否已有明确上下文。主要入口需要被发现；重复工具动作不必反复抢占视线。不将某系统的“主要按钮数量/左右位置”升级为所有页面的定律。
3. **控件处于哪里？** 正文、密集表单、摄影、视频、3D场景与固定导航对边界、对比和占幅有不同要求。结合品牌字形、图形语言、材料与实际背景，而非仅凭“商业/艺术/科技”标签套样式。
4. **什么载体最能解释动作？** 在文字链接、文字命令、图标、可见按钮表面、分段选项、开关、样片、空间热点与连续操控中选择；再决定轮廓、填色、尺度和摆放。圆形、胶囊和无框都不自动更高级。
5. **反馈表达哪种事实？** 普通、悬停、按下、焦点、选中、展开、运行/加载各有语义。反馈要连到真实状态与结果；只为实际存在的过程设计变化。
6. **在真实页面是否成立？** 把主动作、次动作与一项状态控制放进实际媒体/文字中，正常速度操作并修正。简短说明“这个动作在此上下文采用此表达，因为……”，不把长选型表变成用户必填材料。

## 按动作选择结构，再设计表面

| 动作与关系 | 可采用的结构与可见提示 | 主要反例 |
|---|---|---|
| 去某页、资源或可寻址章节 | 真实链接；正文可用下划线/明确指向，主要入口也可有按钮表面 | 用伪按钮丢掉复制地址/新标签能力；所有链接都加大色块切碎阅读 |
| 执行保存、进入、复位等一次命令 | 语义按钮；用相称的填色、轮廓、字重、图形或位置建立操作区域 | 为极简隐藏必要动作；给无关命令同样强的外框与面积 |
| 展开菜单或详情 | 触发器与展开状态对应，文字/符号提供内容关系，关闭和焦点回路明确 | 仅画一个装饰箭头；图标变化与实际面板不同步 |
| 在少量相关值/视图间选一项 | 分段、单选、标签页或可辨样片；当前值持续可见，按数据/导航语义实现 | 把无关命令拼成胶囊组；用一次按下效果冒充持续选择 |
| 开关环境、声音或设置 | 状态开关，或明确下一命令的播放/暂停；名称、图标与作用范围一致 | 同时把图标称当前状态又当下一动作；只靠换颜色解释开/关 |
| 播放、暂停、前后浏览等熟悉媒体动作 | 紧凑图标可成立，轮廓/底面按背景与层级决定；仍有名称和必要提示 | 所有陌生动作也删文字；箭头方向与内容运动轴不一致 |
| 连续调节、拖动或按住施力 | 对象手势、滑块、旋钮或明确按住区域；反馈当前量、范围与释放 | 每次点击都跳固定量却伪装连续控制；把施力强度伪装加载完成率 |
| 在空间中发现、聚焦部位 | 内容锚定热点、短标签、轮廓/符号、接近/选中反馈；保留DOM等价入口 | 热点像纯装饰；巨大框遮住主体；自定义光标成为唯一入口 |

链接和命令的底层语义独立于外形，按[Primer原始说明](https://primer.style/accessibility/design-guidance/links-and-buttons/)核对原生行为。仅当图标对当前受众与上下文足够清楚时减少可见文字，并保留名字、焦点与所需提示；见[IconButton指南](https://primer.style/product/components/icon-button/guidelines/)及[名称与状态](https://primer.style/product/components/icon-button/accessibility/)。

## 网页类型提供条件，不直接指定形状

| 当前页面的主要特点 | 可以优先考虑的表达分工 | 需要保留/避免的事 |
|---|---|---|
| 朴素表单、资料操作、高频工具 | 关键完成动作清楚可见，次要命令更轻；密集工具可用中性/透明表面与可辨图标 | 保留可靠命中、标签与焦点；不为去方框把提交变成难找小字，也不为统一把每行都做成CTA |
| 连续阅读、资料目录、编辑内容 | 导航进入阅读流，引用/目录与段落相连；复制、筛选等命令放在对应对象附近 | 区分导航和命令；无需每个可点击词都独立成块 |
| 摄影、品牌、作品策展 | 内容承担主要视觉重量；阅读入口可用文字/方向线索，关键联系入口有相称强调 | 主入口仍可用填色或明确轮廓；巨大外框、细小无标记文字都需看实际内容代价 |
| 商业产品与服务转化 | 注册/购买/询价明确，了解更多更轻；选项用样片或相关选择结构，导航按密度组织 | 同一页面不同任务可有不同表面；沿品牌语言决定几何，不固定全部胶囊或全部直角 |
| 沉浸3D、影片与高动态背景 | 空间操作贴合对象；全局工具紧凑且稳定，介绍/退出清楚；持续操控有对应反馈 | 检查亮暗与运动背景下的可辨性，必要时加底面/衬托；圆环/图标需解释功能，不硬把场景变成后台工具栏 |
| 媒体浏览或产品近看 | 播放/暂停、进度/页码、前后项、特征展开、材质选项各自表达真实关系 | 同一媒体里也不用一套“文字+填色方框”承担所有职责；当前项、当前值与当前命令不要混读 |

同一网站内，相同职责可以共享语言，不同职责也可使用不同形态。跨主题时检查形式是否仍来自实际主线；“跟上次统一”“默认组件”“换一个主题色”不足以独自支持新表达，但已有品牌系统和相同任务是有效依据。

同一句“看详情”，在资料页可能前往资源，在产品媒体中可能展开特征，在3D里可能聚焦部位；分别需要合适的链接、展开触发器或空间热点。主要入口的选型理由也应包含实际背景、品牌与观看关系，不能只有“因为是主按钮所以填色”。

## 把形式和手感一起校准

- **文字、图标与轮廓共同定比例。** 以目标语言的真实文字、长标签和实际图标看字面、笔画、基线、内间距与光学重量。圆形常适合紧凑符号，不为放一句长标签任意扩大；胶囊、矩形、无框都按具体内容决定，不能只改border-radius算重新设计。
- **强调不只靠填色。** 面积、位置、明暗、字重、轮廓和与主体的关系都能建立主次。有底面可以帮助忙碌/变化背景上的识别；透明控件在上下文清楚时可更轻，仍需让人看出能操作。
- **运动解释动作。** 指向性的箭头/下划线、压下反馈、局部展开或真实强度环可采用；命中区保持稳定，运动可在内部视觉层发生。磁吸、追随、拉伸只在帮助当前体验时使用，不让用户追着入口走；详见[交互接续](interaction-craft.md)。
- **选中、焦点与按下分开。** 焦点指出输入位置，选中保留值，按下确认受理。播放图标、文字和开关范围一致；原生控件激活、表单输入与模态焦点须按实际上下文处理。
- **过程反馈可信。** 长任务或不能操作时解释当前结果，保留相应状态与焦点；即时命令不添加假等待。按住反馈表示真实施力/进程，不杜撰百分比。减少动态时保留操作、状态与焦点；持续场景的控件继续遵守既有时钟和输入归属。

用户明确指出同质化、或一个重要动作的形式难以判断时，挑该动作在真实页面做少量有依据的表达比较，固定内容、位置意图与输入结果再看差异。没有这个缺口就直接选型实看，不强制按钮变体墙、样式切换器或额外本人审批。

## 实屏核对

先用鼠标和键盘完成动作与返回，再检查普通/悬停/焦点/按下及实际存在的选择、展开、加载状态；点击后残留悬停不能单独证明纯悬停效果。图标有可理解的名字，提示不遮挡必要内容；隐藏文字并不免除语义。

可访问名包含实际可见的动作文字与必要编号，不用另一套短标签覆盖完整的可见名称。优先让原生文字形成名字，额外说明与状态按职责补充；纯装饰与必要动作线索分别处理。对比度检查在最终背景和实际字号下进行，修正辅助文字可读性时保留主次，不一律加粗或删除说明来通过扫描。自动扫描与实际键盘/返回分别检查，见[浏览器验收](browser-verification.md)。

变化背景看必要亮暗与中段，固定导航/热点不能抢主内容或随镜头失去命中；窄屏按实际窗口和长标签重排，检查图标提示与动作组归属。可见轮廓与命中区域可以不同，具体设备可用性要实际操作；不将CSS尺寸当实体触摸通过。

以当次实际卡住或读错的关系修订，不把圈、方框或某种颜色列为普遍禁令。记录观察、作者规范、迁移建议和未测；不用样式数量、品牌名或一次成功操作推断效率、转化或审美接受。

## 从实际操作修正，而非继承案例外形

把问题记成“触发条件 → 用户看不清/做不了什么 → 原因 → 局部修正 → 原路径复走”，再提取适用条件。例如展览界面可能出现透明区域透出台线、近看时字幕落到暗模型上、部位入口隐藏后焦点丢失，以及环顾后空格没有到达手动响应。以下按触发条件归纳修法；圆环、取景框与任何配色均不自动成为模板。

| 实际条件 | 修正时保持的关系 | 可迁移到的其他主题 |
|---|---|---|
| 背景在摄影、视频、换色或近看过程中改变 | 看当前及必要中段的字/图形对比与穿透干扰；按内容选局部衬托、轮廓、换位或表面，不自动整块填色，也不为透明牺牲识别 | 产品换色、影像栏目、浅色工具浮层；不沿用展场的浅色衬底到所有背景 |
| 按住、拖动或调节会持续改变对象 | 反馈绑定真实输入量/对象响应；按下、持续与释放分别可见，命中区稳定；选滑块、对象手势、数值或其他合适载体 | 音量、画笔压力、材质预览；环形只在量与布局适合时选择 |
| 一个入口在展开、切换或转场后被隐藏/替换 | 等新状态及可见目标已经更新，再交接到同任务的可用入口；新操作取消旧待处理焦点，不让延迟回调抢走用户 | 表单分步、商品特征层、编辑工具面板；目标按下一动作决定，不统一聚焦退出 |
| 同一按键在画布、按钮、输入框或模态中有不同含义 | 按焦点与当前模式分配；保留原生按钮激活、文本输入和模态范围，实走鼠标转键盘路径 | 媒体播放器、画布编辑器、普通表单；不无条件全局截获Space/Enter |
| 自动过程暂停后仍允许用户直接操作 | 名称、当前状态和下一命令说明实际作用对象/范围，区分自动推进、环境与手动输入；即时反馈不等待自动时钟 | 自动轮播与手动翻页、产品自转与拖动；不因此给简单页面增加多组开关 |

内容锚定入口随当前对象更新；需要跟随形变时才绑定真实表面/特征，不用固定偏移假装贴合。内容不可见、被挡或进入文字安全区时，可换锚点或提供同内容的稳定入口。此原则也适用于图片标注和重排列表，不要求所有页面使用3D顶点或射线。

复验保留触发问题的原路径，至少覆盖这次改动影响的进入、输入切换、状态变化和返回；只有截图或构建通过不能证明交接成立。核对真正选中的页面与实际尺寸，稳定状态读数和即时采样分开；未测的悬停瞬态、实体触摸、读屏或持续性能按实记录。沿用已验证证据，不因更新方法重复全站测试。

迁移前重新回答动作、层级、内容背景和品牌条件。朴素表单仍可保留清楚的保存按钮，商业页仍可采用符合品牌的填色入口，阅读页仍可主要使用链接；没有背景变化、连续输入或入口替换时，不加对应机制。验收依据是当前内容与操作是否成立，不是用了几种形状。

## 来源带来的条件与边界

| 来源 | 可研究的关系 | 可迁移条件 |
|---|---|---|
| [Lusion](https://lusion.co/) | 联系、菜单、声音与表单命令按各自职责组织 | 学习同站动作分工，另核对当前键盘、关闭与播放行为，不照搬形状 |
| [Infinite Passerella](https://exp-infinite-passerella.lusion.co/) | 相机/自由视角、灯光动作及说明层的图形、标签和状态 | 让场景保留主体地位；陌生图标需解释，不因圆形省略可用入口 |
| [GOV.UK Button](https://design-system.service.gov.uk/components/button/) | 官方按主要/次要动作及真实后果组织按钮与标签 | 功能完成动作可保留清楚表面；不继承整套颜色、位置和网站类别配方 |
| [Primer Button](https://primer.style/product/components/button/) | 官方区分强调、普通、透明等变体及焦点 | 功能界面也可减轻表面；可辨性、名字和状态继续成立 |
| [Apple产品页](https://www.apple.com/macbook-pro/) | 购买入口、媒体控制、特征展开与变体选项承担不同工作 | 同一商业页可按职责分工；不推断转化收益或沿用品牌资产 |
| [Stripe](https://stripe.com/) | 商业入口与密集产品导航的层级关系 | CTA可用清楚填色，与文本导航区分；不把矩形视为失败 |

本页是条件性制作方法，原站不是完整无缺陷范本，也没有由此证明新作品的悬停瞬态、触摸或跨设备表现。来源与归属见[来源说明](../SOURCES.md)；研究图像不作为新站或Skill的可复制素材。
