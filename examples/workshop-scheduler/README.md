# 同作工坊 · 设备排班

一个面向每天反复使用的工坊工作人员的完整可运行示例。核心是同屏比较三台设备的预约与空闲时段：激光切割机、3D 打印机、CNC 雕刻机。界面使用中文，虚构数据覆盖 2026-10-26 至 2026-11-01，每日开放 09:00–18:00，以半小时为单位。

## 运行

需要 Node.js 20 或更高版本，无第三方依赖。从仓库根目录运行：

```powershell
node examples/workshop-scheduler/serve.mjs
```

打开 <http://127.0.0.1:4301>。可用 `AFD_DEMO_PORT` 覆盖端口：

```powershell
$env:AFD_DEMO_PORT = '4305'
node examples/workshop-scheduler/serve.mjs
```

服务仅监听 `127.0.0.1`。页面资源和 API 请求使用相对路径；将本目录作为独立服务根目录时无需改写资源路径。**需要此示例服务处理 API；纯静态文件服务不能保存预约。**

## 实际路径

- 日期按钮与设备下拉框筛选同一套数据；三栏时间轴保留对照关系。窄屏时间轴可在独立区域横向滚动，设备筛选可切为单栏，详情移到时间轴下方。
- 「新建预约」或空闲格打开原生对话框。填写名称、使用人、设备、日期和时段后保存。空闲格默认预约半小时，可调整结束时间。
- 点击预约查看详情，再选择「调整预约」或「取消预约」。取消有独立确认，默认焦点放在「保留预约」。取消成功后通知内可撤销；若时段后来被占用，服务拒绝恢复并保留当前排班。
- 服务返回成功前不在时间轴插入预约。等待期间禁用重复提交和表单修改；失败保持全部输入，允许重试。网络错误后的重试复用同一请求标识，避免服务已保存而客户端未收到响应时重复预约。改变输入生成新标识。
- 对话框使用原生 `dialog`；表单有明确标签、必填项和可见焦点。Tab/Shift+Tab 在模态范围内，Enter 提交表单；非保存期间 Escape 返回。提交中须等服务确认，关闭控件明确禁用。无全局快捷键拦截。

## 可控模拟服务

首页明确标注「演示工作区 · 虚构资料」「本地模拟服务」。所有姓名、项目和预约均为虚构，无账号、生产数据库或真实设备控制。数据存在 Node 进程内存中，服务重启后重置；浏览器刷新会重新读取当前服务数据。

普通排班页面没有故障按钮。开发人员单独打开 <http://127.0.0.1:4301/diagnostics.html>，为下一次新的写入设置：

| 场景 | 服务行为 | 页面预期 |
| --- | --- | --- |
| 成功 | 默认约 260 ms 后写入并返回预约 | 关闭表单、显示结果，选中保存的预约 |
| 延迟 | 等待 2.2 秒再执行 | 显示等待，禁用重复操作，未提前占用时段 |
| 失败 | 503，不写入预约；场景自动消耗 | 错误消息，输入保留，可重试 |
| 冲突 | 模拟同事抢先占用待保存时段，返回 409；若调整仍覆盖自己原时段，则模拟他人更新该条版本并返回 STALE，避免制造重叠数据 | 更新背后时间轴，保留表单和输入；修改时段再提交，或关闭后重新打开最新版本 |

设置是进程内、一次性的，作用于下一次新的写入；GET 和成功请求的幂等重放不会消耗场景。失败的请求允许用同一个键重试。诊断适配器也可直接调用：

```js
await fetch('./api/__demo/control', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ mode: 'delay', delayMs: 2200 })
});
```

API：`GET ./api/reservations`；`POST ./api/reservations/create|update|cancel|restore`。写入要求 `Idempotency-Key`，同键同请求只执行一次，同键不同内容返回 409。修改、取消和恢复要求 `expectedRevision`，服务拒绝过期版本。服务校验日期、设备、开放时间、半小时粒度、名称长度和时段重叠，邻接时段允许共存。

诊断控制仅适合此本机演示。这里没有持久化、账号鉴权、跨进程锁、生产日志或生产部署流程。

## 文件与设计来源

- `index.html` / `styles.css` / `app.mjs`：页面、响应式样式和真实异步交互。
- `data.mjs`：七天虚构数据及三台设备；无外部图片、图标或字体请求。
- `service.mjs`：内存模拟服务、校验、版本与幂等逻辑。
- `serve.mjs`：免依赖的本机 HTTP 服务；仅公开页面所需资源。
- `service.test.mjs` / `http.test.mjs`：行为与真实 HTTP 测试。
- `diagnostics.html`：与普通工作页面分离的开发诊断入口。
