# 岸线 · 自然写作刊物

公开 Skill v0.20 的完整独立示例，版本 `journal-first-pass-1`。阅读优先、非 3D；原创虚构散文与 AI 概念影像均显式说明。

## 运行

需要 Node.js 20+，无需安装依赖。在本目录运行：

```sh
node serve.mjs
```

默认入口为 `http://127.0.0.1:4302`，仅监听 loopback。环境变量 `AFD_DEMO_PORT` 可覆盖端口。静态资源与模块均使用相对路径，也可把整个目录放在任意静态站点子目录。

## 页面与路径

- `#/`：本期封面、编者短笺、专题目录、延伸入口。
- `#/contents`：直接抵达专题目录。
- `#/article/tide`、`#/article/forest`、`#/article/rain`：三篇完整原创散文，每篇约 1,300 个中文字。
- `#/article/<id>/image`：同篇影像近看；提供关闭、原生对话框键盘焦点约束和 Escape 退路。
- `#/about`：刊物、文字与 AI 影像创作说明。
- 无效文章或路径：明确空页与返回本期目录入口。

文章地址可以复制、独立打开、刷新与使用浏览器前进/后退。关联阅读把来源文章 ID 与历史条目保留在当前历史状态，提供有名字的返回入口；独立抵达则回到目录。滚动位置保存在每条历史记录与当前标签页 sessionStorage 中；禁用存储时仍使用历史状态。图片近看不替换文章 DOM，退出恢复原触发按钮焦点与文章位置。

## 内容与视觉决定

封面并排安排期名/编者语与河口概念影像，目录以编号、文章名和小幅图像构成连续索引；林下与雨后补充入口采用不同观看尺度。文章页收束成单栏中文长文，桌面章节导航位于侧边，窄屏重排到正文前。没有滚动联动的正文动画。仅封面影像有轻微悬停放大；减少动态时取消过渡。

中文标题与正文优先使用本机宋体族，操作文字使用本机黑体族，无字体网络依赖；不同操作系统的实际字形会略有差异。本站不加载第三方脚本、追踪或在线服务。

三篇为不同叙述：潮间处理等待与空手离开；林下处理观看尺度与身体姿势；雨后处理日常停留与不保存的时刻。影像来源与最终提示词见 [ASSETS.md](ASSETS.md)。

```sh

```

首版已通过 4 项 Node 检查：正文长度与影像标记、路由解析（含无效路径）、关联来源返回/独立抵达纯函数、静态 HTTP 与相对资源/拒绝路径越界和写请求。所有三个 PNG 已逐张查看，符合概念图主题；这不构成真实摄影或科学事实核验。

浏览器验收由协调者负责。首版作者未完成实屏排版、真实鼠标/键盘、近看退出位置、实际前进后退/刷新、手机设备、连续动效手感、剪贴板权限或辅助技术验收。一次独立无头浏览器启动因缺少对应可执行文件失败，未启动浏览器也未运行其路径断言；不计作通过。

这些检查和作者自查不代表用户本人接受，亦不代表 Skill 在其他题材上的普遍效果。
