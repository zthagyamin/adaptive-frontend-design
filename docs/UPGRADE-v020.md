# v0.2.0 implementation and acceptance

The upgrade starts from public v0.1.0 and keeps installed/private editions separate. It is a candidate until the two complete pages receive human visual/feel feedback and the final changes pass validation.

## Deliverables

1. Real-browser regression alongside existing package and Node checks. Chromium on pull requests; WebKit smoke checks on main. Failures retain local report, screenshot and trace outside the installable Skill.
2. A complete shared-workshop scheduler: a fictional week, three machines, half-hour slots, filtering, create/edit/cancel/undo, controlled asynchronous success/delay/failure/conflict and keyboard forms.
3. A complete non-3D nature journal: three substantive fictional essays, original concept images, topics, direct article URLs, history, related reading and image inspection with correct return.
4. A separate motion lab: native-scroll composition, direct surface response and a decaying particle field, with interruption, reduced motion, reset and resource ownership.
5. Asset/performance/accessibility checks, then bounded guidance changes and independent runnable transfer slices. Preserve the eight existing behavioral cases and prior failures.

## Acceptance

Check actual desktop 1280×800 and narrow 390×844 layouts, plus 1024/320 boundaries, keyboard, 200% text/layout zoom and reduced motion. Automated scans do not establish full accessibility; unavailable physical touch and screenreader paths remain untested. Byte budgets for these examples start at 1.5 MiB for the non-3D first view and 2 MiB for the motion lab; measured exceptions need a reason. Compare timings only in a matched environment.

Source checks, browser behavior, continuous observation, author assessment and human acceptance are separate records. No website palette, shape, layout or fixed parameter becomes a universal rule. No real account, payment, production reservation service or nature observation is implied.

Package/plugin 0.2.0 and final publication wait for the acceptance gate. A draft PR may carry the implementation and evidence first.
